# Sample corpus

Fictional documents for a fictional organisation (the Aurora Institute). Replace them with your
own. Each file needs front matter with an `id`, a `title` and a `classification` (`public`,
`internal`, `restricted` or `confidential`). Files above the service's classification ceiling are
never loaded.

`it-helpdesk-notes.md` contains a planted instruction aimed at AI assistants, on purpose: the
evaluation checks that it never reaches an answer.
